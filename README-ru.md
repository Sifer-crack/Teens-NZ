# МолодЁЖ

Русскоязычное сообщество подростков Новой Зеландии и Австралии.
Статический многостраничный сайт — без сборки, фреймворков и зависимостей.

## Структура

```
index.html              # Главная (точка входа)
pages/                  # Остальные страницы сайта
  about.html  events.html  news.html  join.html  contacts.html
assets/
  css/style.css         # Общие стили (тёмная тема по умолчанию)
  js/nav.js             # Мобильное меню (гамбургер)
  js/theme.js           # Переключатель тёмной/светлой темы
  img/                  # Изображения (например, логотип сообщества)
```

## Запуск

Без сборки. Открой `index.html` в браузере — всё работает из коробки. Dev-сервера,
линта, тестов и typecheck нет.

## Окружение

`.env.example` содержит значения-плейсхолдеры (`TELEGRAM_BOT_URL`, `CONTACT_EMAIL`,
`COMMUNITY_NAME`). Скопируйте в `.env` и заполните при необходимости. Сейчас сайт
полностью статичен — ничего из `.env` в рантайме не читается; эти переменные
предназначены для будущего хостинга, API или сборки.

## Деплой

Статический сайт автоматически деплоится на Cloudflare Pages через GitHub Actions
(`.github/workflows/deploy.yml`). Без шага сборки — корень репозитория загружается как есть.

| Ветка  | Проект Cloudflare Pages | URL |
| ------ | ----------------------- | --- |
| `main` | `teens-nz-prod`         | `nzslavteens.com` |
| `dev`  | `teens-nz-dev`          | `dev.nzslavteens.com` |

### Необходимые секреты репозитория GitHub
- `CLOUDFLARE_API_TOKEN` — токен Cloudflare с правом **Account → Cloudflare Pages → Edit**.
- `CLOUDFLARE_ACCOUNT_ID` — ID аккаунта Cloudflare (из дашборда или `wrangler whoami`).

### Настройка Cloudflare (один раз)
1. Создайте два проекта Pages и задайте имена `teens-nz-prod` и `teens-nz-dev`.
2. Привяжите кастомные домены: `nzslavteens.com` на продакшн-проект,
   `dev.nzslavteens.com` на dev-проект.
3. Укажите DNS на соответствующие `<project>.pages.dev`.

## Заметки

- Весь пользовательский контент — **на русском**. Новый текст пишите на русском.
- Навигация и подвал **продублированы вручную** во всех 6 HTML-файлах — при правках
  синхронизируйте все страницы.
- Тёмная тема — по умолчанию; светлая через `data-theme="light"` на `<html>`.
  Состояние сохраняется в `localStorage["molodezh-theme"]`.
- Логотип сообщества лежит в `assets/img/main-group-logo.png` и отображается в
  шапке (brand) на каждой странице.
